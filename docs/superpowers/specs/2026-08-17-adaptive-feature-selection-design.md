# 自适应特征选择与高阶组合发现设计

> 日期：2026-08-17  
> 分支：`exp/adaptive-feature-search`  
> 基线提交：`5fa1caf`  
> 状态：设计已确认，分阶段实施

## 1. 背景与目标

当前数据包含 323 个匿名特征。生产流程主要按训练窗口内的单变量绝对 Pearson 相关性排序，
Ridge、截面 LightGBM、市场 LightGBM 和 history 最终都受到固定 `200/200/200/40` 列数的约束。
这个方法速度快且在折内计算，不泄漏未来信息，但存在五个结构性限制：

1. 单变量弱相关的特征可能只在组合中有效；
2. 多个高相关特征会重复表达同一信号，挤占模型容量；
3. 市场、截面、历史任务的目标不同，不应默认共用同一组选列；
4. 特征作用可能随时间、市场状态或另一个特征所处区间改变；
5. 固定列数把结果预先限制在 200/40，而不是让严格 OOF 决定需要多少特征。

本设计的目标是从完整匿名特征池中学习四个模型专属集合，并记录高阶交互结构：

```text
S_R  = Ridge 自适应特征集
S_XS = 截面 LightGBM 自适应特征集
S_M  = 市场 LightGBM 自适应特征集
S_H  = history 自适应基础特征集
G    = 由条件效应和高阶组合构成的交互超图
```

最终特征数量不预设。数量由嵌套 rolling OOF 的边际收益、稳定性、噪声地板和运行成本共同决定。

## 2. 不做什么

本路线明确排除：

- 不用公榜选择特征、阈值、模型或融合参数；
- 不枚举 323 个特征的所有二元或高阶组合；
- 不因看到中间结果后临时扩充候选矩阵；
- 不在首阶段修改生产模型或生成公榜 CSV；
- 不把相关性低直接等同于无用，也不把相关性高直接等同于应保留；
- 不把 `200/200/200/40` 当作新流程的固定终点。

## 3. 总体流程

```text
任务分解
  -> 质量、稳定性与漂移审计
  -> 冗余模块识别
  -> 条件残差相关性
  -> 非线性与阈值效应
  -> 条件区间交互
  -> 浅树路径挖掘
  -> 随机子空间搜索
  -> Beam Search
  -> 浮动前向/后向剪枝
  -> 嵌套 rolling OOF
  -> 模型分量与融合耦合分析
  -> lambda / blend / scale 联合重标定
```

该流程不是一条一次性流水线。每一阶段只把通过稳定性门禁的候选交给下一阶段，失败候选留下报告，
但不继续消耗完整重训预算。

## 4. 严格验证协议

### 4.1 外层 OOF

沿用生产等效协议：

```text
n_folds       = 5
train_window  = 78,960 sampled time_ids
embargo       = 6
sample_modulo = 5
sampling      = phase_balanced
```

每个外层验证折只能用于最终比较。预处理、特征筛选、阈值学习、聚类代表选择、模型超参数和融合参数
都必须只在该折训练窗口内部完成。

### 4.2 内层四时间块

每个外层训练窗口按时间顺序切成四个连续内层块。它们用于：

- 估计特征效果的中位数；
- 计算方向一致率和离散度；
- 检测早期到晚期的漂移；
- 学习条件区间阈值；
- 选择 Ridge alpha、LightGBM 容量和候选特征集合；
- 估计边际 OOF 增益的噪声地板。

阈值不能在外层验证折上拟合。任何分箱边界、树路径或组合规则都必须由内层训练数据产生。

## 5. 四种任务视图

### 5.1 Ridge 视图

目标为完整 `target`，权重使用官方训练权重。特征候选包含稳健预处理后的 raw 与截面 deviation。
筛选重点是稳定线性增量、共线性控制和正则化后的边际贡献。

### 5.2 市场视图

对每个 `time_id` 聚合特征均值，并构造市场目标：

```text
xbar_tj = mean_i(x_itj)
m_t     = sum_i(w_it * y_it) / sum_i(w_it)
```

市场 LightGBM 预测共同时间成分，因此应在这个聚合任务上评估特征，而不是复用截面目标选出的列。
为了匹配当前市场森林训练口径，审计同时报告无权和带权聚合差异，但选型口径必须预先冻结。

### 5.3 截面视图

构造：

```text
e_it = y_it - m_t
d_itj = x_itj - mean_i(x_itj)
```

截面 LightGBM 的候选特征在 `d_itj -> e_it` 任务上评估。除 pooled 统计外，还要计算逐时间截面 IC、
IC 中位数、正向比例和时间块稳定性。

### 5.4 History 视图

history 只允许使用因果状态。每个基础特征可派生四类列：

```text
previous
difference
rolling mean
rolling deviation/state
```

选择单位首先是“基础特征”，而不是把四个派生列当作四次独立机会。一个基础特征进入 history 后会增加
四个模型列，因此容量和运行成本必须按四倍列数计入。

## 6. 第一阶段：结构审计

### 6.1 质量指标

每个任务、每个特征至少记录：

- finite 比例、NaN/inf 比例；
- 标准差、IQR、常数比例和极端值比例；
- 与任务目标的 Pearson/Spearman；
- 四时间块效果、中位数、MAD、方向一致率；
- 早期块与晚期块的效果差；
- 分布漂移，如标准化均值差和 PSI 类分箱漂移。

审计不直接决定最终集合。它提供后续筛选的可追溯输入，并识别“看似强但只在一个时期有效”的特征。

### 6.2 冗余模块

对每个任务分别计算稳定 Pearson 与 Spearman 关系。只有在多个内层块中都保持高相关的特征对，
才视为稳定冗余。距离可写为：

```text
distance(j,k) = 1 - median_b(abs(corr_b(j,k)))
```

再用层次聚类形成模块。模块内不强制只留一个特征，而是产生三类候选：

- 代表特征：稳定性和任务相关性最好；
- 备选特征：在部分状态下提供差异化作用；
- 组合特征候选：模块均值或代表特征的正交残差。

显式的模块均值、差值和正交残差要延后生成，只有模块在嵌套 OOF 中稳定共选后才允许进入模型。

### 6.3 融合耦合

当前融合写成：

```text
b = m_R + e_R
u = m_L - m_R
v = e_L - e_R
f = b + lambda * u + blend_weight * v
```

对每折计算加权 Gram 矩阵：

```text
G_ab = sum_i(w_i * z_ai * z_bi) / sum_i(w_i * y_i^2)
z = [b, u, v, y]
```

其中 `<u,v>_w` 衡量 `market_lambda` 与 `blend_weight` 的耦合。它不为零时，单独调一个参数会改变另一个
参数的有效最优点。因此任何新特征集合通过后，都必须重新做联合重标定，不能沿用旧最优点并假设独立。

## 7. 条件残差相关性

单变量相关性回答“特征本身是否跟目标同向”，条件残差相关性回答“在已有集合解释之后，它是否还提供
新信息”。对当前集合 `S`，先在内层训练块拟合基模型，得到训练外残差 `r`，再测候选 `x_j` 与 `r` 的关系。

Ridge 使用线性残差增量；树模型同时测 raw、rank 和分箱后的残差增量。候选必须在多个时间块中保持方向
或保持一致的非线性形状，不能只靠 pooled 样本量取得微小显著性。

## 8. 非线性、阈值与条件区间交互

用户关心的典型情形是：当特征 A 落在某个范围时，特征 B 的影响方式改变。该现象可表示为：

```text
E[y | A, B] != g(A) + h(B)
```

检测步骤：

1. 在内层训练数据上按 A 的分位数生成候选阈值；
2. 分别拟合仅含 A/B 主效应的加法模型与允许联合分区的浅树模型；
3. 比较训练外残差和 Peak 增量；
4. 检查不同时间块中阈值是否接近、B 的局部斜率或单调方向是否一致；
5. 只有联合模型稳定胜过加法模型时，才把 `{A,B,区间}` 写入交互图。

这类检测不限于二元规则。一个浅树路径天然表达：

```text
A > a0 AND B <= b0 AND C > c0 -> 局部效应
```

路径中 3 至 6 个不同特征可形成一个超边，避免手工穷举所有三元、四元组合。

## 9. 高阶组合发现

### 9.1 浅树路径挖掘

在每个任务和内层块上训练强约束浅树，记录反复出现的 3 至 6 特征路径。路径按出现块数、训练外增益、
符号/叶值稳定性和跨折复现率排序。

### 9.2 随机子空间

从通过质量门禁的模块代表与备选中，抽取大小为 `3/5/8/16/32` 的随机子集。比较其训练外表现与组成
特征的加法基线，寻找“单个弱、组合强”的结构。抽样种子和预算在运行前冻结。

### 9.3 Beam Search

以稳定单特征和稳定模块为起点，每轮只扩展排名前 K 个集合。评分包含：

```text
score = OOF gain
        - instability penalty
        - redundancy penalty
        - runtime/capacity penalty
```

Beam Search 允许发现三元以上组合，但不会像全组合搜索那样指数爆炸。

### 9.4 组消融

对候选超边进行整组加入、整组删除和成员删除。只有“整组有益且不能被一个成员完全解释”的组合，
才保留为真实高阶候选。

## 10. 自适应集合构造

每个模型分别执行浮动前向/后向过程：

1. 从稳定基线集合或空集合开始；
2. 按条件残差增益加入单特征、模块或超边；
3. 每次加入后重新检查已选成员，删除被新成员替代的冗余项；
4. 在内层 OOF 上选择 Ridge alpha 或固定预算下的 LightGBM 容量；
5. 当边际增益低于噪声地板、稳定性下降或运行成本超限时停止；
6. 用 one-SE 规则选择更简单的集合，而不是选择均值最高但不稳定的集合。

停止条件综合：

- mean paired Peak 增量；
- 至少 4/5 外折同号；
- drop-best 仍为正；
- `2*delta_A > delta_B`；
- 边际增益超过重复运行/块间波动形成的噪声地板；
- 集合在外折间的 Jaccard 稳定性；
- 推理时间和内存预算。

## 11. 模型容量归一化

特征数量改变会同时改变模型容量，必须避免把“多列”误判为“更好筛选”。

- Ridge：`alpha` 在每个外层训练窗口的内层折重新选择；报告有效自由度或系数范数。
- LightGBM：调整 `feature_fraction`，使每棵树期望采样列数与基线可比；必要时把总 split 预算作为辅助指标。
- History：一个基础特征等于四个模型列，运行成本按派生后列数计算。
- 融合：特征集合确认后，使用 OOF 分量重新联合求 `lambda/blend/scale`，不固定旧 `0.7/1.17` 为永久最优。
