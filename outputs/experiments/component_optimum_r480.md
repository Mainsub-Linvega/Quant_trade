# 分量最优配比（闭式解）

`Score(c) = 2aᵀc − cᵀMc` 是凹二次型 → `c* = M⁻¹a`、`peak = aᵀM⁻¹a`。
**配比是纯后处理（参数三分类第①类），不花公榜额度。**

源 CSV `submission_r480_s116.csv` @ scale 1.16：
`A = 0.00234971`（精确）、`B = 0.00213228`（由公榜点 scale 1.16 / 分 0.0025821304 反解）。
现在的单一 scale 模型峰值 **0.00258931**（IC 0.05089）。
